## 2. 取证结论

- 三次「闪退」对应同一 PID 13670 全程存活：无 `am_proc_died`、无 tombstone、无 crash buffer、无 ANR、无 lowmemorykiller 记录。
- 窗口事件为 `wm_finish_activity reason=app-request`（15:03:08.980、15:04:01.266、15:04:11.697），随后 `wm_destroy_activity` / `wm_task_removed`。
- 即：不是进程级崩溃，而是导入过程中 Activity 被结束；选择结果进入 LostDataStore 后从未被取回，用户感知为「闪退且什么都没发生」。
- 客观诱因：`am_pss` 显示进程约 386 MB（swap 492 MB），vivo `am_app_frozen`（fast_freezer）频繁冻结/解冻，存在系统内存压力下中断的前提。
- 本轮所有样张与用户文件均无法复现，结论：**暂不可复现**。

## 4. 下次遇到时的取证步骤

1. 先接 USB，手动开启全量抓取（不要做成常驻）：
   `adb -s 10CDAB0F5C001TJ logcat -v threadtime > logs\device-<时间戳>.log`
2. 复现后立刻看窗口/进程事件：
   `adb -s 10CDAB0F5C001TJ logcat -b events -d | findstr /C:"wm_finish_activity" /C:"am_proc_died" /C:"am_crash" /C:"am_anr"`
3. 看应用私有日志：
   `adb -s 10CDAB0F5C001TJ shell run-as com.homepdfreader.app cat files/logs/app.log`
   关注 `[BOOT] 上次未正常退出` 与 `[IMPORT]` 各阶段最后一条。
4. 系统侧证据：
   `adb -s 10CDAB0F5C001TJ shell dumpsys dropbox --print | findstr homepdfreader`
   `adb -s 10CDAB0F5C001TJ logcat -b crash -d`
5. 仍无痕迹时出完整报告：`adb -s 10CDAB0F5C001TJ bugreport`。
