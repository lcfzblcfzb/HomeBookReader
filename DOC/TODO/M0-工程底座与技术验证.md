## 4. 遗留问题

1. **Windows C++ 工具链（已解决）**
   - 原现象：`VC\Tools\MSVC\14.44.35207` 只剩 `cl.exe`，`include` 与 `lib\x64` 为空；`vswhere -requires Microsoft.VisualStudio.Component.VC.Tools.x86.x64` 无结果；`vcvarsall.bat` 不存在。
   - 处理：清理 C 盘并退役 VS 包缓存到 `D:\VSPackages` 后，用 `setup.exe install --productId Microsoft.VisualStudio.Product.BuildTools --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended --installPath D:\BuildTools` 安装成功；`vswhere` 现可识别。
2. material 3.50 的 `package:flutter/material.dart` 弃用提示，待统一迁移 `material_ui`（不影响功能）。
