## 1. 背景与目标

侧边方案落地后，入口是一整张猫图，静止时头部也露着，视觉上像「贴在边上的贴纸」。改为有生命感的语义：

- **静止（idle）**：整张素材沿屏幕外法线方向推出，屏幕内只剩底部一截（爪部），像爪子扒在边上；不露头。
- **拖拽（dragging）**：仍以爪为主，允许被拉扯的轻微形变；不露头。
- **激活（active，面板打开）**：位移归零，整张素材收回到入口内，头部露出；带轻微回弹。
- **方向**：书签的「上」= 所贴边的「外」。贴右边时素材顶端朝屏幕右外侧，贴左边时朝左；旋转角度与锚边绑定配置，不写死。
- 位移比例、时长、曲线全部进配置。
- 面板关闭回落、转屏、拖动吸附、点击翻页热区、遮罩与返回键行为不得退化。

**实现方式：等比显示 + 整体平移，不使用裁剪、缩放或非等比拉伸。** 素材按 `BoxFit.contain` 等比缩放到入口内（源图 96×96 → 实际绘制 40×40 dp，宽高比 1:1 与源图一致），三态只差位移：静止推出、拖拽极小幅外移、激活归零。内部 `Stack` 用 `Clip.none`，允许素材部分移出可视区而不被意外裁掉。

## 2. 方案

### 2.1 位移语义

素材在自身坐标系是横向的 132×40，外层 `RotatedBox` 旋转 90°，使素材「顶端」朝向屏幕外侧：

| 贴边 | quarterTurns | 素材顶端朝向 |
| --- | --- | --- |
| 右侧（默认） | 1（顺时针 90°） | 屏幕右外侧 |
| 左侧（预留） | 3（逆时针 90°） | 屏幕左外侧 |

- 静止：沿素材 −y（= 屏幕外法线方向）平移 `entryThickness × entryStaticOutwardRatio`（40 × 0.72 ≈ 29 dp），屏内只剩素材底部约 28%，即爪部。
- 激活：位移归零，整张素材回到入口内，头部露出。
- 拖拽：位移在静止值上再加 `pullOffset`（2 dp）表达「被拉扯」，入口整体跟手；不做任何形变。
- 素材自身按 `BoxFit.contain` 等比绘制：96×96 源图在 132×40 的绘制盒里渲染为 40×40 dp，宽高比与源图一致。
- 位移由 `Transform.translate` 承担；`Stack(clipBehavior: Clip.none)` 保证不被内部布局裁掉，真正越出屏幕的部分由屏幕与入口形状自然裁掉。
- 入口命中区仍是 `entryThickness × entryLength`（40×132 dp），不随素材缩小而变化。

### 2.2 动画

- 独立 `AnimationController`（`entryHeadRevealDuration = 280 ms`）+ `CurvedAnimation`（`entryHeadRevealCurve = Curves.easeOutBack`），收尾超调形成轻微回弹。
- 由 `_syncEntryState` 统一驱动：目标态 `active` → `forward()`，其余 → `reverse()`；`initState` 按初始态直接置 1/0，避免首帧瞬变。
- 进度 0 → 1 映射为位移 `-29 dp → 0`，即「从边缘往屏幕内收回、头部露出」。

### 2.3 三态视觉

- 去掉状态驱动的缩放（原 1.08 / 1.03）与倾斜，三态只差：阴影（可保留）与 `pullOffset`（仅拖拽 2 dp）。
- 过渡仍由 `entryStateTransitionDuration` 统一插值，避免瞬变。
- 不露头：位移保持静止值，头部仍在屏幕外。

### 2.4 配置项（`ReaderUiConfig`）

| 参数 | 现值 | 用途 |
| --- | --- | --- |
| `entrySide` | `BookmarkEntrySide.right` | 贴边侧，决定旋转与圆角方向 |
| `entryQuarterTurns` | 由 `entrySide` 推导：右 1 / 左 3 | 素材顶端朝屏幕外 |
| `entryInnerRadius` | 由 `entrySide` 推导 | 内侧两角圆角 |
| `entryStaticOutwardRatio` | 0.72 | 静止时推出厚度占入口厚度的比例 |
| `entryHeadRevealDuration` | 280 ms | 收回 / 推出时长 |
| `entryHeadRevealCurve` | `Curves.easeOutBack` | 收尾回弹 |
| `entryStateVisuals` | idle 无阴影；dragging 阴影 + `pullOffset = 2`；active 阴影 | 三态只差阴影与极小位移，无缩放/旋转 |
| `collapsedVisibleRatio` | 1 | 不再靠折叠藏头，入口完整贴边（参数保留，改回 0.5 即恢复折叠露出） |

### 2.5 将来换成两张分层素材

现在只有一张整图，靠整体位移实现两态。若后续提供「只含爪子的图 / 单独的头」：

1. 两张图加入 `assets/images/bookmark/` 并声明；
2. `BookmarkEntryArtwork` 里叠两层（爪部在下、头部在上），两层共用同一个 `headReveal` 位移，头部层额外可加透明度/缩放；
3. 位移比例、时长、曲线、状态机、吸附与面板逻辑全部复用，不改交互；
4. 若两图比例不同，只调整各自的绘制尺寸配置。
