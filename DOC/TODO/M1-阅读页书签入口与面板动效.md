## 1. 任务清单

### 1.1 顶部书签入口

- [x] 入口从右下角移到屏幕顶部居中，横向长条贴住上沿，不占竖向阅读空间
- [x] 展开态占位尺寸 132×40 dp，代码绘制，圆角仅下方两角、半径 12 dp
- [x] 预留剪影资源位（`assets/images/bookmark_tab.png`），支持 `ColorFilter` 染色，亮暗主题共用
- [x] 资源缺失时回退到代码绘制的占位形状

### 1.2 折叠 / 展开 / 面板动效

- [x] 默认藏在屏幕上沿外，露出高度为折叠比例（0.5）可配置
- [x] 手指按下立即滑出（200 ms，先快后缓），不等抬手
- [x] 抬手时手指仍在入口区域内 → 打开面板（250 ms 从顶部滑入）
- [x] 抬手时已移出入口区域 → 回弹折叠
- [x] 关闭面板后入口回到折叠态

### 1.3 手势与配置

- [x] 入口区域吃掉自身手势，不触发左右翻页
- [x] 折叠比例、时长、曲线、tint 色、资源路径集中在一个配置文件
