## 1. 背景与目标

M1-012 之后入口仍贴顶，与 Android 顶部下拉手势天然冲突（API 30 上排除区不覆盖通知栏）。改为**侧边方案**：

- 入口整体旋转 90°，变成竖向条，贴**当前朝向的右侧边缘**（竖屏贴长边、横屏贴短边）。
- 沿侧边上下拖动，松手吸附回右侧边，纵向位置按朝向分别记忆。
- 三态（idle / dragging / active）与参数化视觉保留。
- 顶部专用逻辑（顶部手势排除区、32 dp 顶部安全余量）清理；排除区改为保护右侧边（返回手势区）并实测。
- 面板改为从右侧横向滑入/滑出，内容与遮罩不变。

左侧贴边作为可选配置，本轮不做。

## 2. 方案

### 2.1 几何与布局

`BookmarkEntryLayout` 由「上边横坐标」改为「右侧边 + 纵向范围」：

| 字段 | 含义 |
| --- | --- |
| `right` | 入口盒右边缘的横坐标（= 屏宽 − 右安全区），恒贴右侧边 |
| `minTop` / `maxTop` | 入口盒上边缘的纵向可用范围（安全区内） |
| `initialTop(ratio)` | 无历史位置时贴右上角；有比例时按比例还原 |
| `ratioOf(top)` | 纵向坐标转 0..1，用于按朝向持久化 |

- 竖屏、横屏各一份纵向比例；转屏后按新朝向的 `right` 与自身比例重新贴边。
- 配置重命名：`entryLength`（沿边长度 132）、`entryThickness`（垂直边厚度 40），语义不再依赖「上/下」。
- 删除 `entryTopInset` 与 `BookmarkEntryLayout.touchInset`。

### 2.2 渲染

- 原有 132×40 内容用 `RotatedBox(quarterTurns: 3)`（逆时针 90°）旋转：原底边转到屏幕右侧贴边，原顶边朝屏幕内侧；圆角只取屏幕内侧两角。
  > 实施时由顺时针（1）改为逆时针（3），保证素材朝向与「爪贴边、头朝内」一致。
- 三态视觉沿用 `entryStateVisuals`，阴影偏移由纵向改为横向（指向屏幕内）。
- 折叠逻辑保留但默认关闭：M1-014 改为「静止只露爪、激活才露头」后 `collapsedVisibleRatio = 1`，入口完整贴边；参数保留，可随时恢复折叠露出。

### 2.3 手势

- 按下 → 滑出；超过 `kTouchSlop` → dragging；原地松手 → 激活面板。
- 拖动跟手（仍可二维移动），松手吸附回右侧边，纵向取松手点并 clamp。
- 拖动结束不误触打开面板。

### 2.4 系统返回手势

- 右侧边有系统返回手势带（Android 10+）。继续复用 `homepdfreader/gesture_exclusion` 通道，把入口竖向矩形报给系统；系统对左/右边按**高度**计 200 dp 预算，入口高 132 dp，无需额外余量。
- 上报时机：入口可见、吸附落点变化、转屏（含朝向标记变化）、面板开关；离开阅读页清空。
- 实测：入口处上下滑可拖动、入口外侧上下滑仍能返回。

### 2.5 面板

- 从右侧横向滑入/滑出，右侧留出入口厚度（`panelSideOffset`），入口保持可见且不被遮罩压暗。
- 宽度 = `min(屏宽 × panelMaxWidthRatio, panelMaxWidth, 可用宽度)`；左上/左下圆角；`SafeArea` 保留上、下、左。

### 2.6 位置记忆兼容

- 旧键 `reader.entry_x.portrait` / `reader.entry_x.landscape` 存的是顶部吸附的横坐标，纵向不能沿用。
- 新键 `reader.entry_y.portrait` / `reader.entry_y.landscape`；`load` 发现新键缺失时删除旧键，升级后回到贴右上角，不出现错位。
