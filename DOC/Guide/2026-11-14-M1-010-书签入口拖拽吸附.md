## 1. 目标

1. 入口初始位置改到屏幕右上角，折叠露出比例仍是 50%。
2. 按住可自由拖动，松手后平滑吸附回当前朝向的「上侧边」，横坐标取松手点。
3. 「上侧」跟随朝向：竖屏短边在上、横屏长边在上；旋转后重新贴顶。
4. 竖屏、横屏分别记住横坐标，下次进入阅读页沿用。
5. 吸附后仍能点开面板，面板仍从入口下沿滑入；不影响左右翻页点击区与沉浸式系统栏。

## 2. 实现

### 2.1 布局与安全区

新增 [bookmark_entry_layout.dart](../../lib/features/reader/presentation/bookmark_entry_layout.dart)：

| 字段/方法 | 说明 |
| --- | --- |
| `isLandscape` | 当前朝向，参与布局相等判断（旋转必重新贴顶） |
| `minLeft` / `maxLeft` | 入口盒左边缘可用范围，来自 `MediaQuery.padding` 左右安全区 |
| `top` / `maxTop` | 吸附后的顶边与拖动纵向上限，来自上下安全区 |
| `initialLeft(ratio)` | 比例为 null 时返回 `maxLeft`（右上角），否则按比例还原并 clamp |
| `ratioOf(left)` | 横坐标换算成 0..1 比例，用于持久化 |
| `clampLeft` / `clampTop` | 拖动与吸附时的边界约束 |

安全区选择 `MediaQuery.padding` 而不是 `viewPadding`：沉浸式下系统栏隐藏时 padding 为 0，入口仍贴屏幕物理上沿；打孔/刘海保留的安全区会参与 clamp，避免被裁。

### 2.2 拖动与吸附

[bookmark_entry.dart](../../lib/features/reader/widgets/bookmark_entry.dart) 由「顶部一条居中入口」改为「铺满阅读区的 Stack + 单个 Positioned 入口」：

- 空区域不参与命中，点击照常落到下层 [page_turn_layer.dart](../../lib/features/reader/widgets/page_turn_layer.dart)，左右翻页不受影响。
- 指针按下：记录起点并展开入口（保持原「按下即滑出」手感）。
- 移动超过 `kTouchSlop` 进入拖动：位置 = 按下时的位置 + 手指位移，并 clamp 在安全区内；纵向可自由拖到屏幕下方。
- 抬手且发生过拖动：不再判定为点击；横坐标取松手点，纵向用 `entrySnapDuration = 260 ms`（`easeOutCubic`）平滑回落到顶边，完成后回弹折叠。
- 抬手且未拖动：沿用原逻辑——仍在入口内则打开面板，否则折叠。
- 吸附动画中途再次按下：从当前动画位置接着拖，不跳变。
- 旋转/窗口尺寸变化：`didUpdateWidget` 检测到 `layout` 变化后取消拖动与吸附；换朝向用新朝向记住的比例，同朝向仅尺寸变化时按原比例保持。

### 2.3 位置记忆

新增 [reader_entry_position_repository.dart](../../lib/data/repos/reader_entry_position_repository.dart)，复用 `app_meta` 表，不需要新表或迁移：

| key | 内容 |
| --- | --- |
| `reader.entry_x.portrait` | 竖屏横坐标比例（0..1，6 位小数） |
| `reader.entry_x.landscape` | 横屏横坐标比例 |

- 存比例而不是绝对像素：Windows 改窗口大小、不同屏宽都能还原到相近位置。
- 阅读页在文档就绪前并行读取两份位置，读完再显示入口，避免首帧位置跳变。
- 吸附开始时立即回报并落库，动画中途退出也不会丢位置；读写失败只记 WARN，界面回退右上角。

### 2.4 面板

[reader_page.dart](../../lib/features/reader/presentation/reader_page.dart) 的面板 `top` 从固定 `panelTopOffset` 改为 `安全区上边距 + ReaderUiConfig.panelTopOffset`，仍从入口下沿滑入，不随入口横坐标变化。

## 5. 说明与后续

- 入口仍按位置记忆**全局**生效，不区分文档；如需按文档记忆，可在 key 中追加 documentId。
- 面板横坐标不跟随入口，仍是整宽从入口下沿滑入；如希望面板也对齐入口，可再加水平平移。
- 横屏时如果设备有侧边打孔，安全区会把可滑动范围收窄，入口不会滑到摄像头下方。
