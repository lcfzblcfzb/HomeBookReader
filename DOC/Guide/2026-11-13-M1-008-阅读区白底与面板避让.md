# 更新摘要：阅读区白底与书签面板避让

- 前置：[M1-007 书签入口图与安卓可见性](./2026-11-13-M1-007-书签入口图与安卓可见性.md)

## 1. 目标

1. 手机竖屏页面按宽度适配后上下留黑边，改为白色阅读区底色，并把颜色做成可配置值。
2. 书签面板打开时盖住顶部入口，改为面板整体下移，入口保持完整可见。

## 2. 改动

| 文件 | 变更 |
| --- | --- |
| `lib/features/reader/presentation/reader_ui_config.dart` | 新增 `readerBackgroundColor`（白）、`readerForegroundColor`（深灰）、`panelTopOffset`（= 入口高度） |
| `lib/features/reader/presentation/reader_page.dart` | Scaffold 底色改配置值；错误/渲染失败提示改用配置前景色；面板容器从 `top: panelTopOffset` 开始并 `ClipRect`；入口移到浮层之后 |

### 2.1 阅读区底色

- `Scaffold.backgroundColor = ReaderUiConfig.readerBackgroundColor`，页面按宽度适配后上下留白随底色变成白色。
- 同步把错误态图标/文字、渲染失败提示从 `Colors.white70` 改为 `readerForegroundColor`，避免白底上看不见；夜间模式只需改这两个颜色值。

### 2.2 面板避让

- 面板容器改为 `Positioned(top: panelTopOffset, bottom: 0)`，滑入位移仍由 `FractionalTranslation` 控制；外面套一层 `ClipRect`，滑入途中向上溢出的部分被裁在入口下沿，动画过程也不会盖住入口。
- 入口从浮层之前移动到浮层之后（Stack 最后一个子节点），因此打开面板时猫图不会被 0.35 遮罩压暗；遮罩只压暗入口两侧与页面。
- 关闭后仍走原反向动画，入口回到折叠态。

## 4. 后续

- 夜间模式：把 `readerBackgroundColor` 切到深色，并同步调整 `readerForegroundColor`；面板配色目前仍跟主题 `colorScheme.surface` 走。
- 面板起始位置由 `panelTopOffset` 控制，入口高度变化时会自动跟随。
