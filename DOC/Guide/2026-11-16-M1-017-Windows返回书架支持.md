# 更新摘要：Windows 返回书架支持

- 日期：2026-11-16
- 关联 TODO：[M1-017 Windows 返回书架支持](../TODO/M1-017-Windows返回书架支持.md)
- 类型：三端交互补齐 / 阅读页外壳 / 书签面板
- 范围：阅读页 Esc 键（Windows）返回书架、书签面板「书架」按钮；
  **不做**其他 Windows 快捷键（翻页 / 缩放 / 打开）、鼠标侧键、多窗口

## 1. 目标与结果

| 目标 | 结果 |
| --- | --- |
| Windows 无系统返回键，需要 Esc 路径 | `ReaderShell` 包 `CallbackShortcuts`（Esc）+ `Focus(autofocus)`，事件沿焦点链兜住 |
| Esc 行为与安卓返回键一致 | 面板打开先 `closeBookmarks()`；面板关闭 `context.go('/')` 回书架，进度落库与沉浸式恢复照常 |
| 书签面板显式「书架」入口 | 面板头部「关闭」按钮前新增 `TextButton.icon`（`Icons.library_books` +「书架」），任意页签可见，紧凑密度与「当前位置/当前页」按钮同规格 |
| PDF 与 EPUB 行为一致 | 两种阅读页共用 `ReaderShell`，一处实现两端生效 |
| 不影响安卓 | 返回键走 `PopScope` 原逻辑不变；「书架」按钮三端通用 |

## 2. 实现

- [reader_shell.dart](file:///d:/ToolProjects/HomePdfReader/lib/features/reader/presentation/reader_shell.dart)：
  `PopScope` 内加 `CallbackShortcuts(SingleActivator(escape))` + `Focus(autofocus: true)`；
  `_onEscape()` 分支处理。外壳接线 `onGoToBookshelf: () => context.go('/')`。
- [bookmark_panel.dart](file:///d:/ToolProjects/HomePdfReader/lib/features/bookmarks/presentation/bookmark_panel.dart)：
  新增必填回调 `onGoToBookshelf`；头部按钮放在「关闭」前，页签行已是
  `Expanded + 横向滚动`，窄屏不溢出。
- 返回书架统一 `context.go('/')`，与错误态「返回书架」、`ReaderHostPage` 一致。

  面板「书架」按钮返回书架。假会话驱动真外壳 + go_router 断言路由。

  重新进入 → 面板按钮回书架，全部通过。

## 4. 环境限制记录（重要）

- flutter test 框架拉起的 App 进程在本机被拒绝写 `AppData`（Roaming/Local）与
  `Temp`（errno 5 拒绝访问），仅允许写工程目录；**既有 `m1_smoke_test.dart`
  在同一环境下同样失败**（PDF 解析正常，复制到私有目录阶段被拒），属环境限制
  而非代码回归。普通 dart 进程与用户终端直接运行的应用不受影响。
- 因此本条冒烟用假会话驱动真外壳，覆盖「真实窗口 + 真实按键」关键路径；
  「导入 → 阅读 → Esc 回书架」完整链路留待用户终端手工复核。
