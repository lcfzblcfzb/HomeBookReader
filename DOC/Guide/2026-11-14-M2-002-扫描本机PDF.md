## 1. 目标

导入流程新增「扫描本机 PDF」：遍历本机存储，只列 PDF，显示文件名 / 目录 / 大小，支持多选批量导入，导入走现有入库与封面流程；Android 权限方案先行确认，Windows 端同能力。

## 2. 权限结论

| 系统 | 最少权限 | 用户看到什么 | 代价 |
| --- | --- | --- | --- |
| Android 11+（API 30+） | `MANAGE_EXTERNAL_STORAGE` | 系统设置「All files access」页内一个开关，打开后返回应用 | 不能上架 Google Play；权限面宽 |
| Android 7–10（API 24–29） | `READ_EXTERNAL_STORAGE` | 常规运行时授权弹窗 | 分区存储下仅能读共享目录 |
| Windows | 无 | 无 | 遍历耗时，需跳过系统目录 |

- 不用 MediaStore：覆盖不全且返回 content Uri，导入仍需拷贝。
- SAF 目录授权（`ACTION_OPEN_DOCUMENT_TREE`）列为后续可选「轻权限」替代，不作为默认。
- 本项目 targetSdk 36 / minSdk 24，因此「全盘」代价 = 一次去设置页手动开开关；折中方案即 SAF 单选目录，后续按需再做。

## 3. 实现

| 层 | 变更 |
| --- | --- |
| `android/app/src/main/AndroidManifest.xml` | 新增 `READ_EXTERNAL_STORAGE`（maxSdkVersion=29）、`MANAGE_EXTERNAL_STORAGE` |
| `android/.../MainActivity.kt` | 新增 MethodChannel `homepdfreader/storage_access`：`status` / `request` / `root`；API≥30 用 `isExternalStorageManager()`，`request` 跳 `ACTION_MANAGE_APP_ALL_FILES_ACCESS_PERMISSION`（失败回退全局页）；API<30 走 `requestPermissions` 并在 `onRequestPermissionsResult` 回填 |
| `lib/core/platform/storage_access.dart` | 新增：`StorageAccess.status()` / `request()` / `androidRoot()`；非 Android 返回 `notRequired` |
| `lib/features/scan/application/pdf_scan_service.dart` | 新增：`Isolate.spawn` 栈式遍历，每 150ms 回传进度，`onCancel` 发消息并 kill isolate；PDF = 扩展名（大小写不敏感）+ 文件头 `%PDF-`（读前 5 字节），头不对标 `looksBroken`；路径去重；跳过系统/缓存目录；结果按小写文件名排序 |
| `lib/features/scan/application/scan_controller.dart` | 新增：权限状态、扫描进度、结果与选择、导入汇总；「已在书架」按 `标题(去扩展名,小写)|大小` 匹配；导入失败原因回填到条目标签 |
| `lib/features/scan/presentation/scan_page.dart` | 新增扫描页：权限卡（说明 + 去授权 + 重新检查）、扫描中（进度 + 取消）、空态、结果列表（`CheckboxListTile`）、底部「已选 M/N + 导入选中」 |
| `lib/features/library/presentation/library_page.dart` | 「+」与空态按钮改为底部弹窗：选择 PDF 文件 / 扫描本机 PDF |
| `lib/app/router.dart` | 新增 `/scan` |

扫描根目录（`ScanController._scanRoots()`）：
- Android：`/storage/emulated/0` + `/storage` 下除 `emulated`/`self` 的外置卷。
- Windows：`%USERPROFILE%` 下 Downloads / Documents / Desktop / OneDrive + D:–Z: 固定盘（系统盘不整盘扫）。

## 4. 验收

| 验收项 | 方式 | 结果 |
| --- | --- | --- |
| 只出 PDF | 模拟器放 `notes.txt` | 不进列表 |
| 扩展名大小写 | `Sample_Upper.PDF` | 正常列出并可导入 |
| 路径与大小 | 列表副标题 | `/storage/emulated/0/Download/scan_test` + `15.5 KB` |
| 已导入区分 | 同名同大小文档 | 标「已在书架」；同内容不同名（sha256 相同）判重复不重复入库 |
| 坏文件 | `sample_broken.pdf` | 导入失败，条目标「无法导入」，应用不崩（日志 `[WARN] [IMPORT] 扫描导入失败`） |
| 多选导入 | 选 4 个 → 2 成功 1 重复 1 失败 | 书架出现 2 本，封面正常，SnackBar 汇总 |
| 扫描中可交互 | 409 个 PDF | 扫描页显示「正在扫描… 已扫描 354 / 发现 283」，可取消；界面未冻住 |
| 大结果集 | 409 条 | 列表懒构建，滚动流畅 |
| 空结果 | 移走 PDF 后重扫 | 「没有找到 PDF 文件 / 已扫描 71 个文件」+「重新扫描」 |
| 未授权 | `appops set ... deny` | 显示权限卡；点「去授权」进入系统 All files access 页；开开关返回后自动重扫出列表 |
| Windows 分支 | 真实目录 `test_assets` 跑扫描服务 | 6 个 PDF，名称/目录/大小正确，非 PDF 排除 |
| 单测 | `flutter test` | 24 条通过（含 5 条扫描用例） |
| 静态检查 | `flutter analyze` | 仅既有 `material.dart` deprecated info，无 error/warning |
