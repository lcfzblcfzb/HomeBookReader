## 1. 目标

阅读模式的书签浮层面板里能看大纲，点条目跳到对应页；沿用现有浮层风格，不新增常驻控件。

## 2. 实现

| 层 | 变更 |
| --- | --- |
| `core/pdf/outline_flatten.dart` | 新增：outline 树深度优先扁平化（`level` / `parentIndex` / `sortOrder`）、当前章节反查（最后一个目标页 ≤ 当前页的条目） |
| `data/db/daos/toc_dao.dart` | 新增 `TocDao`：`listByDocument` / `isParsed` / `replaceAll`（事务内整体替换 + `app_meta` 标记） |
| `data/repos/toc_repository.dart` | 新增 `TocRepository.loadOrParse()`：缓存优先，首次解析后落库 |
| `app/providers.dart` | 新增 `tocRepositoryProvider` |
| `features/reader/application/reader_controller.dart` | 新增面板页签状态、目录列表/加载/错误状态；打开文档后在后台解析目录，不阻塞首屏；新增 `selectPanelTab()` |
| `features/bookmarks/presentation/bookmark_panel.dart` | 头部改为「书签 / 目录」轻量页签；目录内容接入 `TocList`；空态按是否有文字层给出不同文案 |
| `features/toc/presentation/toc_list.dart` | 新增目录列表：层级缩进（20 + 16×层）、单行截断、当前章底色/色条/主题色、页码展示、点击回调 |
| `features/reader/presentation/reader_page.dart` | 接线目录数据与跳页（关闭面板后 `goTo(pageIndex)`） |

页码约定：`toc_entries.page_index` 与跳转都用文档内部 0 基页码，仅界面显示 `+1`。

## 3. 验收

| 验收项 | 方式 | 结果 |
| --- | --- | --- |
| 目录列出与层级 | 模拟器 `sample_text_en` | 4 条，2 层缩进正确，页码 1/5/5/9 |
| 当前章节标记 | 第 8 页打开 | 高亮「2.1 小节（第 5 页）」 |
| 点击跳页 | 点「第 3 章」 | 面板关闭，页脚变为 `page-9`、正文 `Page 9 of 12` |
| 空态 | `sample_scanned` | 显示「该文档是扫描件，没有可用的目录。」 |
| 缓存 | 二次打开 | 目录正常显示，应用日志无新的「目录解析完成」 |
| 单测 | `flutter test` | 19 条通过（含扁平化/当前章节） |
| 集成 | Windows `m1_smoke_test` | 通过，目录非空且页码在文档范围内 |
| 静态检查 | `flutter analyze` | 无 error/warning，仅既有 deprecated info |
