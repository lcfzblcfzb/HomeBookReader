- 前置：[M1-010 拖拽吸附](./2026-11-14-M1-010-书签入口拖拽吸附.md)、[M1-011 三态状态机](./2026-11-14-M1-011-书签入口三态状态机.md)、[M1-012 手势排除区](./2026-11-14-M1-012-书签入口手势排除区.md)

## 1. 目标与取舍

贴顶方案在 API 30 上无法彻底规避「顶部下拉通知栏」：系统排除区对通知栏无效，只能靠把入口下移 32 dp 兜底，且仍有约 30 dp 落在系统手势带里。改为**侧边方案**：

- 入口整体旋转 90°，呈竖向条，贴**当前朝向的右侧边缘**（竖屏贴长边、横屏贴短边）。
- 纵向拖动、松手吸附、按朝向分别记忆位置。
- 顶部专用逻辑（顶部排除区语义、32 dp 顶部余量）清理，排除区改为保护右侧边的系统返回手势带。
- 面板从右侧横向滑入/滑出，内容、遮罩、关闭逻辑不变。

左侧贴边作为可选配置预留，本轮不做。

## 2. 几何与布局

`BookmarkEntryLayout` 由「上边横坐标」改为「右侧边 + 纵向范围」：

| 字段 | 含义 |
| --- | --- |
| `isLandscape` | 当前朝向，决定使用哪一份位置记忆 |
| `right` | 入口盒右边缘横坐标（屏宽 − 右安全区），恒贴右侧边 |
| `minTop` / `maxTop` | 入口盒上边缘纵向可用范围（`media.padding` 安全区内） |
| `initialTop(ratio)` | 无历史比例时贴右上角（`minTop`）；有比例时按比例还原 |
| `ratioOf(top)` | 纵向坐标转 0..1，用于持久化 |

- `span`、`clampTop(top)` 提供纵向夹取；配置语义改为 `entryLength`（沿边长度 132）、`entryThickness`（垂直边厚度 40）。
- 删除 `entryTopInset`、`BookmarkEntryLayout.touchInset` 与 `entryImageFit`，不再有无效的「顶部余量」通道调用。

## 3. 渲染

- 入口内容以 `RotatedBox` 旋转 90°：贴右边时 `quarterTurns = 1`（顺时针），素材顶端（初始实现为底边，见 M1-014 修正）朝屏幕右外侧；旋转角度与贴边侧绑定在 `ReaderUiConfig.entrySide`，不写死在组件里。
- 圆角 `BorderRadius.horizontal(left: ...)` 只作用于屏幕内侧两角（由 `entrySide` 推导）；阴影偏移改横向（指向屏幕内，负 x）。
- 三态视觉表 `entryStateVisuals` 与过渡参数保留；后续 M1-014 去掉了缩放与倾斜，三态只差阴影与极小位移。
- 折叠比例参数保留，但 M1-014 改为「静止只露爪、激活才露头」后置为 `collapsedVisibleRatio = 1`，入口完整贴边。

## 4. 手势

- 按下 → 滑出；位移超过 `kTouchSlop` → dragging；原地松手 → 激活面板（`onActivate`）。
- 拖动跟手（允许二维移动，横向越界会被 clamp）；松手吸附回右侧边，纵向取松手点并 clamp，落点比例通过 `onSettled` 回报上层落库。
- 拖动结束不会误触打开面板；入口只命中自身矩形，空区域透传给下层左右 1/3 翻页点击区。

## 5. 系统返回手势

- 右侧边是 Android 10+ 的返回手势带。复用 `homepdfreader/gesture_exclusion` 通道，把入口竖向矩形（`entryThickness × entryLength`）报给系统。
- 系统对左/右边按**高度**计 200 dp 预算，入口高 132 dp，一条即可容纳，无需额外余量。
- 上报时机：入口可见、吸附落点变化、转屏（含朝向标记）、面板开关；离开阅读页 `clear()` 清空。相同矩形 + 相同朝向 + 相同面板状态去重。

## 6. 面板

- 从右侧横向滑入：`Positioned(top: 0, bottom: 0, right: safe.right + panelSideOffset, width: width)` + `ClipRect` + `FractionalTranslation(Offset(1 - progress, 0))`。
- `panelSideOffset = entryThickness`，面板右边缘与入口内边缘对齐，入口始终可见且不被遮罩压暗。
- 宽度 = `min(屏宽 × panelMaxWidthRatio, panelMaxWidth, 可用宽度)`；`BorderRadius.horizontal(left:)` + `SafeArea(top/bottom/left)`。
- 遮罩点击关闭、返回键先关面板的逻辑未改。

## 7. 位置记忆兼容

| 键 | 说明 |
| --- | --- |
| `reader.entry_x.portrait` / `reader.entry_x.landscape` | 旧方案（贴顶）横坐标，升级后不再有语义 |
| `reader.entry_y.portrait` / `reader.entry_y.landscape` | 新方案纵向比例 0..1 |

`ReaderEntryPositionRepository.load` 只读新键；新键不存在时顺手删除对应旧键，返回 `null`，入口回到贴右上角。这样升级后不会把「横坐标」当作纵向比例导致位置错乱。

环境：`Pixel_5_API_30`（1080×2280，dpr 2.75），debug APK，手势导航（`navigation_mode=2` + gestural overlay）。

| 重进沿用 | 返回书架再进 | 沿用 878，不跳回顶部 |

## 10. 回归

- 三态 idle / dragging / active 与过渡：保留，参数仍走 `entryStateVisuals`。
- 拖动不翻页：入口命中区只有自身矩形。
- 左右 1/3 点击翻页：入口厚度 40 dp 只吃掉右边缘一条，其余区域正常翻页。
- 遮罩关闭、返回键关闭：未改。
- 沉浸式：进出阅读页隐藏/恢复系统栏的逻辑未改。
