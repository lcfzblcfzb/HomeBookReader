# 更新摘要：EPUB 分页阅读页（第二步）

- 日期：2026-11-16
- 关联 TODO：[M1-016 EPUB 阅读页](../TODO/M1-016-EPUB阅读页.md)
- 类型：新阅读形态 / 自定义分页 / 阅读页外壳重构 / 排版设置
- 范围：EPUB2 / EPUB3 的分页阅读、跨章翻页、目录与书签、字号行距重排、位置恢复；
  **不做**滚动、划线/批注、全文搜索、翻页动画、双栏

## 1. 目标与结果

| 目标 | 结果 |
| --- | --- |
| 分页而非滚动 | 用 `TextPainter` 按可用宽高切页，页面按排版结果绝对定位渲染 |
| 左侧上一页 / 右侧下一页 / 中间不翻 | 复用 `PageTurnLayer`，与 PDF 共用同一套点击分区 |
| 跨章连续翻页 | 章末自动懒排版下一章；上一页跨回上一章末页 |
| 全书末尾提示 | SnackBar「已到全书末尾」，不越界、不白屏 |
| 目录 `href + fragment` 跳转 | 锚点换算成章内字符偏移，跳到包含该字符的排版页 |
| 书签入口 / 面板 / 返回键 | 抽取 `ReaderShell`，PDF 与 EPUB 完全共用入口、三态、位置记忆、面板滑入、返回键先关面板 |
| 排版基本样式 | 标题 h1–h6 层级、段首两全角缩进、段间距、图片等比居中、列表、引用、粗/斜/下划线 |
| 字号 5 档 / 行距 2 档 / 页边距 1 档 | 书签面板新增「排版」页签；组件独立，可整体搬走 |
| 改字号落回同一段 | 重排后按当前字符偏移找回页，不回到章首 |
| 进度 `position` | `(章序号 + 章内字符比例) / 章数`，跨字号、屏幕尺寸、横竖屏恢复；书架显示百分比 |
| 按章懒排版 | 只解析/排版当前与相邻章，缓存 3 章；单章逐页让出主线程 |
| 中文界面 | 错误、提示、页签名、排版档位均为中文 |

## 2. 数据与进度模型（schema v3）

| 表 | 变更 |
| --- | --- |
| `bookmarks` | `page_index` 改为可空；新增 `position REAL NULL`；`pos_y` 保留 |

- `AppDatabase.schemaVersion = 3`，`TableMigration(bookmarks, newColumns: [bookmarks.position])` 重建表。
- `BookmarkRepository.add` 改为 `add({documentId, pageIndex, position, posY, label})`：
  PDF 写页码，EPUB 写 0–1 位置；默认标签 PDF「第 N 页」、EPUB「位置 N%」。
- `ProgressDao.watchAll()` + `ProgressRepository.watchAll()`：书架订阅全部进度，
  `LibraryController` 合并文档流与进度流，`BookTile` 对 EPUB 显示「作者 · 位置 N%」。
- 排版设置存 `app_meta`：`reader.epub.font_level`、`reader.epub.line_spacing_level`，
  由 `ReaderTypographyRepository` 读写，全局生效。

位置公式与恢复：

```
position = (chapterIndex + currentChar / chapterCharCount) / chapterCount
chapterIndex = floor(position × chapterCount)
currentChar = round(intra × chapterCharCount)
page = layout.pageIndexForChar(currentChar)   // 二分找 startChar ≤ 当前字符的最后一页
```

`currentChar` 取页起始字符；页内插图/分隔线不占字符，因此跨字号、转屏后
仍能定位到同一段文字，而不是章首。

## 3. EPUB 包与内容解析

新增 [epub_session.dart](file:///d:/ToolProjects/HomePdfReader/lib/core/ebook/epub_session.dart)：

- `EpubSession.open(file)`：复用 `EpubParser.validate` 校验，解析 container → OPF → manifest → spine。
- spine 只收 XHTML/HTML；缺 spine 时按 manifest 顺序回退并跳过 `properties` 含 `nav` 的文档。
- `readChapter(i)`、`readResource(href)`、`resolveInChapter(...)`。
- `spineIndexForHref(href)` 同时接受目录里的 OPF 相对路径与 spine 的包内完整路径，
  解决 `text/ch1.xhtml` 与 `OEBPS/text/ch1.xhtml` 的差异。

新增 [epub_content.dart](file:///d:/ToolProjects/HomePdfReader/lib/core/ebook/epub_content.dart)：

- `EpubContentParser.parse(xhtml, chapterHref:)` 输出块模型：
  标题 1–6、段落、列表项（层级/有序/序号）、引用、图片、分隔线。
- 行内样式：粗体、斜体、下划线、等宽；`<p><img/></p>` 中的图片单独成图片块，不丢。
- 每个块记录 `startChar`，`anchors` 记录 `id`/`name` → 字符偏移，供 fragment 跳转。
- 解析失败抛 `EpubContentException('本章内容解析失败')`，阅读页只提示本章错误。

## 4. 分页引擎

[epub_typography.dart](file:///d:/ToolProjects/HomePdfReader/lib/core/ebook/epub_typography.dart)：
字号 `14/16/18/20/22`、行距 `1.5/1.8`、页边距 24 dp（横）+ 28 dp（纵），标题倍率由字号推导。

[epub_paginator.dart](file:///d:/ToolProjects/HomePdfReader/lib/features/reader/application/epub_paginator.dart)：

1. 文字块用 `TextPainter`（固定 `StrutStyle` + `forceStrutHeight`）在内容宽度内测量，
   `computeLineMetrics()` 取行高，按剩余高度装行；换页在行边界切分。
2. 段首缩进用两个全角空格 `\u3000\u3000`；列表 `• ` / `1. `；引用一个全角空格 + 斜体灰。
   这些是合成字符，`startChar` 计算时扣除，不影响进度。
3. 图片先解码取原始宽高，按内容宽等比缩放；整张放不下就移到下一页；超过页高则按页高等比缩。
4. 每排完一页 `onPage` 通知 UI 并 `Future.delayed(Duration.zero)` 让出事件循环，
   大章节单章内也是渐进排版；`isCancelled` 用于切章 / 重排时立即停止。
5. `EpubChapterLayout.pageIndexForChar` 二分定位，支撑位置恢复与「重排后落回同一段」。

## 6. 排版设置

[typography_settings_panel.dart](file:///d:/ToolProjects/HomePdfReader/lib/features/reader/widgets/typography_settings_panel.dart)：
独立组件，只接收 `EpubTypography` 与 `onChanged`；字号 5 档 / 行距 2 档 / 页边距说明 + 预览。

改档位后：

1. `setTypography` 持久化设置、清空全部章节排版缓存；
2. 记录当前 `chapterIndex + currentChar`；
3. 重新排版当前章，定位到包含该字符的页，再恢复渲染。

定位期间显示加载态（`_positioning`），不会先闪一下章首。

## 7. 关键修复

| 问题 | 修复 |
| --- | --- |
| 初始化恢复位置的竞态（视口先于进度加载） | `_restoreInitial` 要求 `!_loading` 且无错误 |
| 退出时进度退化为章首 | `dispose()` 先取 `position` 再清章节缓存；`flushProgress` 仍是主路径 |
| 重排/转屏时闪回章首 | `_positioning` 期间 `currentPage` 返回 null，显示加载态 |
| 旧跳转任务覆盖新位置 | `_invalidateLayouts` 递增 `_moveToken`，旧等待直接放弃 |
| 渲染与测量行高/字号不一致 | 共用 `EpubBlockStyle`；`Stack` 按测量值定位；关闭系统字体缩放 |
| 书架点击 EPUB 仍弹「阅读页待做」 | 移除书架拦截，统一跳 `/reader/:id`，由 `ReaderHostPage` 按格式分流 |
| 面板顶部三页签 + 操作按钮在窄屏溢出 1.5px | 页签行改为 `Expanded + 横向滚动`，操作按钮用紧凑密度 |

## 9. 遗留

- 图片渲染用 `Image.memory`，布局只用解码尺寸；极长图片按页高缩放，暂不支持裁切/分块。
- 表格按行合并单元格为段落，未做单元格排版。
- 目录条目当前章按 spine 索引高亮，同一章内多个 fragment 不细分。
- 从章首往前翻到上一章末页时，需要先把上一章排完，超大章节可能出现短暂加载态。
- 真机（非模拟器）上的字体观感与手势返回仍需供应商设备复核。
