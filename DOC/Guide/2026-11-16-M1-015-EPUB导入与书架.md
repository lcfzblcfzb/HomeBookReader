## 1. 目标与结果

| 目标 | 结果 |
| --- | --- |
| 只支持 EPUB2 / EPUB3 | 已支持，其它电子书格式仍按不支持处理 |
| 不只看扩展名 | 校验 ZIP 魔数 + `mimetype` = `application/epub+zip` + container/OPF |
| 损坏/伪装 epub 拒收且不崩 | `EpubInvalidException` → `ImportInvalid(中文原因)`，UI 汇总失败提示 |
| 书架封面、书名、作者 | OPF `dc:title` / `dc:creator`；封面按 OPF 声明取图，缺失用占位 |
| 进度：EPUB 不用页码 | 新增 `reading_progress.position`（0–1），书架显示「作者 · 位置 0%」 |
| 目录 nav + ncx | 两条路径都覆盖，落进 `toc_entries`；`href + fragment`，页码留空 |
| 扫描识别 EPUB | 扫描服务已支持 pdf/epub 混合，其它格式继续排除 |
| 数据平滑升级 | schema v1 → v2，旧 PDF 数据保留，PDF 行为未改 |
| 点开 EPUB 有明确提示 | 书架弹窗「阅读页待做」；阅读控制器深链兜底同样提示 |

## 2. 数据迁移（schema v2）

`AppDatabase.schemaVersion` 从 1 升到 2，新增 `MigrationStrategy`：

| 表 | 变更 |
| --- | --- |
| `documents` | 新增 `format TEXT NOT NULL DEFAULT 'pdf'`；`page_count` 改为可空 |
| `reading_progress` | `page_index` 改为可空；新增 `position REAL NULL`（0–1） |
| `toc_entries` | `page_index` 改为可空；新增 `href TEXT NULL`、`fragment TEXT NULL` |

实现用 drift `TableMigration` 重建表并复制旧列：`documents` 的新列补 `'pdf'`，其余新列保持 null。
`beforeOpen` 打开 `PRAGMA foreign_keys = ON`。

迁移测试 [migration_test.dart](file:///d:/ToolProjects/HomePdfReader/test/data/db/migration_test.dart)
用 v1 原始 DDL 造旧库（含 PDF 文档、页码进度、页码目录），升级后断言：

- 旧文档 `format = 'pdf'`、`page_count = 12` 保留；
- 旧进度 `page_index = 3`、`position = null`；
- 旧目录 `page_index = 5`、`href/fragment = null`；
- 可写入 EPUB 文档与 `href + fragment` 目录。

## 3. EPUB 校验与解析

新增 [core/ebook](file:///d:/ToolProjects/HomePdfReader/lib/core/ebook)：

- [book_format.dart](file:///d:/ToolProjects/HomePdfReader/lib/core/ebook/book_format.dart)：
  `BookFormat` 与扩展名判定，导入与扫描共用。
- [epub_models.dart](file:///d:/ToolProjects/HomePdfReader/lib/core/ebook/epub_models.dart)：
  `EpubBook` / `EpubTocEntry` / `EpubInvalidException`。
- [epub_parser.dart](file:///d:/ToolProjects/HomePdfReader/lib/core/ebook/epub_parser.dart)：
  ZIP + mimetype + container + OPF 校验；元数据、封面、nav / ncx 目录。

关键规则：

1. ZIP 魔数 `50 4B 03 04`；解压失败、缺 `mimetype`、内容不符、缺 `container.xml`、OPF 不存在
   都给出不同的中文原因。
2. 封面优先级：`cover-image` → `meta[name=cover]` → 文件名/id 含 `cover` 的图片；
   找不到、文件缺失、SVG 封面都返回 null，书架用占位图。
3. 目录先 nav 后 ncx；条目 `href` 统一为相对 OPF 目录的路径（URL 解码），片段单独存；
   不支持无 `href` 的纯标题项，解析失败降级为空目录。
4. 所有解析异常收口为 `EpubInvalidException`，导入层不再向外抛。

## 4. 导入链路

[document_repository.dart](file:///d:/ToolProjects/HomePdfReader/lib/data/repos/document_repository.dart)：

- `importFile` 先按扩展名分流：`.pdf` 保持原逻辑（文件头 → 引擎 → 页数/文字层 → 封面），
  `.epub` 走新分支，其它格式提示「仅支持 PDF 与 EPUB 文件」。
- 两种格式共用 sha256 去重；重复文件仍返回 `ImportDuplicate` 并跳转已有条目。
- EPUB：解析 → 复制到 `epubs/{uuid}.epub` → 封面写 `covers/{uuid}.{jpg|png|...}` →
  写 `documents(format='epub', page_count=null, has_text_layer=true)` →
  目录整体写 `toc_entries` 并标记 `toc_parsed`。
- 封面/目录失败不阻断导入；写库失败返回中文 `ImportInvalid`。

## 6. 目录数据

EPUB 目录在导入时已落库，字段语义：

| 字段 | PDF | EPUB |
| --- | --- | --- |
| `page_index` | 0 基页码 | `NULL` |
| `href` | `NULL` | 相对 OPF 目录的包内路径，如 `text/ch1.xhtml` |
| `fragment` | `NULL` | `#` 之后的片段，如 `s1`；无片段为 `NULL` |
| `parent_id` / `level` / `sort_order` | 原样 | 由 nav / ncx 层级与顺序生成 |

`TocList` 对 `page_index == null` 的条目显示「—」且不可点击，避免 EPUB 锚点混进页码跳转。

## 9. 已知限制（下一步处理）

- EPUB 阅读页未实现：点开只给提示，不渲染正文。
- 书架 EPUB 进度固定显示「位置 0%」；阅读页接入后改为读 `reading_progress.position`。
- SVG 封面不做渲染，直接回退占位（未引入 SVG 解码器）。
- 目录仅支持 nav 的 `ol/li/a` 与 ncx 的 `navPoint` 结构；其它自定义导航降级为空目录。
- 封面取 OPF 声明的原图，不做裁切/压缩；超大封面会在书架解码时受 `cacheWidth` 限制。
