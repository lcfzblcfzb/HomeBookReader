### 1.3 代码骨架

| 目录 | 内容 |
| --- | --- |
| `lib/app` | 入口装配、路由（`/`、`/reader/:documentId`、`/settings`）、主题、riverpod DI |
| `lib/core/pdf` | `PdfEngine` / `PdfDocumentHandle` 接口与 domain 模型；`PdfrxEngine`（pdfrx 类型不外泄） |
| `lib/core/geometry` | `PagePoint` / `PageRect` 归一化值对象、`SelectionSplitter`（跨页拆分 / 同行合并） |
| `lib/core/storage` | `AppPaths`（私有目录、相对路径约定） |
| `lib/core/utils` | `sha256OfFile` |
| `lib/data/db` | drift 六张表 + 三个 DAO（documents / progress / bookmarks） |
| `lib/data/repos` | `DocumentRepository`（导入 / 去重 / 封面 / 删除）、`ProgressRepository`、`BookmarkRepository` |
| `lib/features` | 书架、阅读、书签、设置四个 feature 的 presentation/application/widgets |
| `lib/dev` | `spike_main.dart`：M0 技术验证入口（文本 / 目录 / 渲染 / SQLite 基线） |
| `tool` | `gen_test_assets.py`：程序生成样本 PDF |
| `test_assets` | 文字版 / 中文 / 扫描版 / 无目录 / 1200 页 / 损坏 各一份 |
