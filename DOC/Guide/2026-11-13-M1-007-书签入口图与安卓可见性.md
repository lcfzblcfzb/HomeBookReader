## 1. 目标

1. 查清 Android 上「完全看不到书签入口」的原因并修复。
2. 用产品提供的猫图标替换代码绘制的占位长条，几何规则（132×40 dp、折叠 50%、下方两角 12 dp）不变。

## 2. 问题定位

### 2.1 现象与测量

在 `Pixel_5_API_30`（1080×2280，dpr 2.75）上安装当前包并进入阅读页截图，对顶部做像素扫描：

- 入口**确实被绘制**：占位形状边界 `x=358..720`（363 px = 132 dp）、`y=0..54`（55 px = 20 dp），水平中心 539（屏宽 1080 的中点）。
- 位置、尺寸、折叠比例全部正确，**不是没绘制，也不是画到屏幕外**。
- 沉浸式生效，状态栏已隐藏，**入口没有被裁剪**。

### 2.2 根因：对比度，而不是布局

- 占位色 `0xE62E2E2E`（46,46,46，alpha 0.902）叠在纯黑上，实际约 `(41,41,41)`，亮度仅约 16%。
- Android 竖屏按宽度适配 A4 页面，页面上下留黑，入口正好落在**黑色留白**上；Windows 窗口是宽屏，PDF 几乎顶到标题栏，入口下方就是白页（采样窗口列 x=640：`y=31..49` 为入口灰，`y=51` 起为页面白）。
- 所以同一份代码在 Windows「正常可见」、在 Android「看不见」，是背景反差造成的观感差异，不是两端渲染差异。

另外记录一个边界：SystemUI 的 `StatusBar` 窗口覆盖 `[0,0]-[1080,83]`（约 30 dp），入口整块都在这条带内；沉浸式下系统栏隐藏、入口正常显示，一旦系统栏回显（如下拉通知）会被盖住。本轮保留沉浸式，不改几何。

### 2.3 处理

用彩色猫图标替换占位形状，对比度足够，问题消失；没有改动入口盒尺寸、折叠比例、圆角和动画。

## 3. 改动文件

| 文件 | 变更 |
| --- | --- |
| `pubspec.yaml` | 资源目录改为 `assets/images/bookmark/` |
| `lib/features/reader/presentation/reader_ui_config.dart` | 入口图路径改为 `cat-icon@3x.png`；移除 `entryTint`；新增 `entryImageFit` |
| `lib/features/reader/widgets/bookmark_entry.dart` | `ClipRRect`（仅下方两角 12 dp）+ `Image.asset`，不再染色 |

## 4. 资源使用说明

- 目录内四个文件：`cat-icon@1x/@2x/@3x.png` 与 `cat-icon-master@1024.png`，均已在 `pubspec.yaml` 声明。
- Flutter 的倍率资源只认 `2.0x/`、`3.0x/` 子目录，不识别 `@2x/@3x` 文件名，因此这里固定使用 **@3x（96 px）**：入口图按 40 dp 渲染，Android dpr 2.75 下需约 110 px，96 px 基本无损；桌面 dpr 1.0 下为缩小采样，更清晰。
- 不使用母版：1641×1641 解码约 10.8M 像素（≈43 MB），对 40 dp 的图标不划算。
- 图像是彩色的，按要求**不做 `ColorFilter`**，亮暗主题共用同一张。
- 保持 `BoxFit.contain`：猫图 1:1，在 132×40 盒内以 40×40 居中完整显示，左右留空；若要铺满整条入口，把 `entryImageFit` 改成 `BoxFit.cover` 即可（1:1 图会被裁掉上下）。

## 5. 验证

| 验证 | 方式 | 结果 |
| --- | --- | --- |
| Android 可见 | 截图 + 像素扫描 | 猫图可见：`x=493..586`、中心 539.5；折叠露出约 20 dp（47 px 实体像素，四周为图片透明留白） |
| Android 按下展开 | `input motionevent DOWN` 后截图 | 猫图完整滑出（40 dp）✓ |
| Android 抬手开面板 / 点遮罩关闭 | 截图哈希 | 打开面板正常；关闭后 `c1 == c4` ✓ |
| Windows 可见 | 桌面截图 | 猫图居中显示在页面上沿，折叠/展开/面板/关闭均正常 |
| 不触发翻页 | 开合前后截图哈希 | `w2 == w5`、`c1 == c4`，页码与页面内容不变 ✓ |
| `flutter analyze --no-pub` | 静态检查 | 12 条既有 `material.dart` deprecated info，无 error/warning |

## 6. 后续

- 若希望入口恢复「横向长条」观感，可在 `ReaderUiConfig.entryImageFit` 切到 `BoxFit.cover`，或再提供一张 132:40 的横版素材。
- 入口盒仍是 132×40，折叠比例、动画时长与曲线仍在 `ReaderUiConfig` 内集中调整。
