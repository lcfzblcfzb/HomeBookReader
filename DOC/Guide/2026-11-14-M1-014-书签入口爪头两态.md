# 更新摘要：书签入口「静止只露爪、激活才露头」

- 日期：2026-11-14
- 关联 TODO：[M1-014 书签入口爪/头两态](../TODO/M1-014-书签入口爪头两态.md)
- 类型：入口视觉 / 位移动效 / 贴边方向配置
- 前置：[M1-013 侧边吸附](./2026-11-14-M1-013-书签入口侧边吸附.md)
- 素材标准：[书签素材设计规范](../书签素材设计规范.md)

## 1. 目标

入口从「一整张贴纸」改为有生命感的语义：

| 状态 | 视觉 | 触发 |
| --- | --- | --- |
| idle | 整张素材推出屏幕，屏内只剩爪部扒在边上 | 初始 / 面板关闭 |
| dragging | 仍只露爪，整体跟随手指，额外外移 2 dp（无形变） | 按住并移动 |
| active | 位移归零，整张素材收回，头部露出（带轻微回弹） | 面板打开 |

方向规则：书签的「上」= 所贴边的「外」。贴右边时素材顶端朝屏幕右外侧；左侧预留，规则对称。

实现方式为**等比显示 + 整体平移**：素材按 `BoxFit.contain` 等比缩放（源图 96×96 → 绘制 40×40 dp，1:1），不用 `ClipRect` 裁图、不缩放、不非等比拉伸；由同一个组件的位移动画完成三态切换。内部 `Stack` 使用 `Clip.none`，素材可部分移出可视区而不被内部布局裁掉。

## 2. 贴边方向与旋转

`ReaderUiConfig.entrySide` 是唯一方向来源，其余全部推导：

| 配置 | 右侧（默认） | 左侧（预留） |
| --- | --- | --- |
| `entryQuarterTurns` | 1（顺时针 90°），顶端朝右 | 3（逆时针 90°），顶端朝左 |
| `entryInnerRadius` | 左侧两角圆角 | 右侧两角圆角 |

`BookmarkEntry` 中的 `RotatedBox(quarterTurns: ReaderUiConfig.entryQuarterTurns)` 与圆角都读配置，换边只改 `entrySide`。

> 修正记录：M1-013 落地时用了 `quarterTurns = 3`（顶端朝屏幕内侧，头朝内），与本规则相反；本次改为 `quarterTurns = 1`。

## 3. 位移实现

`BookmarkEntryArtwork` 在素材自身坐标系（132×40）里绘制整图：

```dart
outwardOffset = (1 - headReveal) * entryThickness * entryStaticOutwardRatio + pullOffset;
Transform.translate(offset: Offset(0, -outwardOffset), child: ...整图...)
```

- 素材 −y 方向旋转后即屏幕外法线方向，因此只需一个方向、一个标量。
- `headReveal = 0`：推出 `40 × 0.72 ≈ 29 dp`，屏内只剩素材底部约 28%（爪部），贴住屏幕边缘。
- `headReveal = 1`：位移 0，整张素材回到入口内，头部露出。
- 整图用 `BoxFit.contain`：96×96 源图在 132×40 的绘制盒里渲染为 40×40 dp，宽高比与源图一致，不做非等比拉伸。
- `Stack(clipBehavior: Clip.none)`：允许平移后的素材越出内部边界；越出屏幕的部分由屏幕和入口形状（`ClipRRect` 的圆角轮廓）自然裁掉。

## 4. 动画

- `BookmarkEntry` 新增 `_headController`（`entryHeadRevealDuration = 280 ms`）+ `_headReveal`（`entryHeadRevealCurve = Curves.easeOutBack`），加入 `_positionListenable` 参与重绘。
- `_syncEntryState` 在状态迁移后统一驱动：`active → forward()`，其余 → `reverse()`；`initState` 按初始态直接置 1/0，避免首帧瞬变。
- `easeOutBack` 收尾轻微超调，表现为「收回后的小回弹」；曲线与时长均可换。
- 面板关闭 → 状态回 idle → 位移回到推出值，头部重新藏到屏幕外。

## 5. 三态视觉

- `BookmarkEntryStateStyle` 删除 `scale` / `rotation` / `stretch`，只保留阴影与 `pullOffset`（额外向外平移，dp）。
- idle：无阴影、无外移；dragging：阴影 + `pullOffset = 2`；active：阴影、无外移。
- 三态过渡仍由 `entryStateTransitionDuration` 统一插值，仅阴影与位移渐变，不产生形变。
- 位移在拖拽时保持「推出值 + 2 dp」，因此拖拽期间不露头。

## 6. 配置项

| 参数 | 现值 | 用途 |
| --- | --- | --- |
| `entrySide` | `right` | 贴边侧；旋转与圆角都由它推导 |
| `entryStaticOutwardRatio` | 0.72 | 静止推出厚度占比（40 × 0.72 ≈ 29 dp） |
| `entryHeadRevealOffset`（已删除） | — | 改由比例推导，不再单独配置 |
| `entryHeadRevealDuration` | 280 ms | 收回 / 推出时长 |
| `entryHeadRevealCurve` | `Curves.easeOutBack` | 收尾回弹 |
| `entryStateVisuals` | idle 无阴影；dragging 阴影 + `pullOffset = 2`；active 阴影 | 三态只差阴影与极小位移 |
| `collapsedVisibleRatio` | 1 | 不再靠折叠藏头，入口完整贴边（保留参数） |

## 7. 将来换成两张分层素材

1. 两张图（只含爪子的图 / 单独的头）加入 `assets/images/bookmark/` 并声明；
2. `BookmarkEntryArtwork` 改成两层叠加：爪部层在下、头部层在上；
3. 两层共用同一个 `headReveal` 位移（头部层可再加透明度），两层都保持等比显示；
4. 位移比例、时长、曲线、状态机、吸附与面板逻辑全部复用，不改交互。
