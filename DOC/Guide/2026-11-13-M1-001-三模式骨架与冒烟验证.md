## 1. 改了什么

### 1.1 书架模式（settings / library）

- 书架页：标题、页数、封面（`covers/{id}.png`，缺省占位）、空态引导、删除二次确认、导入结果汇总提示；重复导入直接跳转已有文档。
- 导入：`FilePicker.pickFiles`（file_picker 13 的静态 API，返回值即 `List<PlatformFile>`），逐文件汇总成功 / 重复 / 失败。
- 设置页：存储说明与版本占位（`/settings`）。

### 1.2 阅读模式

- 阅读页：黑底全屏，只显示当前页（`RawImage` + `BoxFit.contain`），无工具栏。
- 翻页：点击左侧 1/3 上一页、右侧 1/3 下一页，首末页无动作；单页瞬时切换。
- 渲染：按 `(width × DPR)` 取像素宽（clamp 320–2400），LRU 缓存 3 页，宽度变化清空缓存。
- 进度：进入恢复 `page_index`，翻页 500ms 节流写库，退出 `flushProgress`。
- 异常：文件缺失 / 渲染失败给出可返回的提示态。

### 1.3 书签模式

- 悬浮书签按钮（阅读页唯一常驻控件）→ 遮罩 + 底部浮层面板。
- 面板：按页序列出书签、添加当前页（默认「第 N 页」）、点击跳转、单条删除、空态文案。
- 返回键优先关闭面板（`PopScope`），再次返回才退出阅读页。

### 1.4 数据层

- drift 表：`documents` / `reading_progress` / `bookmarks` / `highlights` / `toc_entries` / `app_meta`（后三张预建，避免 M5 迁移）。
- DAO：`DocumentsDao`（含 `watchAll`）/ `ProgressDao` / `BookmarksDao`；外键 `ON DELETE CASCADE`。
- 仓库：`DocumentRepository`（扩展名 + `%PDF-` 头 + sha256 去重 + 副本 + 封面 + 元数据）、`ProgressRepository`、`BookmarkRepository`。

### 1.5 验证资产

- 新增 [m1_smoke_test.dart](../../integration_test/m1_smoke_test.dart)：Windows 上使用真实 PDFium + SQLite（内存库）跑完整链路。
- 包名统一 `com.homepdfreader.app`（Android + iOS）。

## 2. 影响模块

| 模块 | 影响 |
| --- | --- |
| app-shell | 路由新增 `/reader/:documentId`、`/settings`；`ProviderScope` 注入 engine / db / 三个仓库 |
| feature-library | 导入、列表、删除、设置入口 |
| feature-reader | 单页渲染、点击分区翻页、进度节流保存与恢复、渲染缓存 |
| feature-bookmarks | 悬浮入口与基础面板（M4 继续扩展改名/去重） |
| data-repos / data-db | 首次端到端验证通过；导入/删除/级联/去重行为确定 |
| core-pdf | 依赖 `textLines` 行级结果（M5 使用），M1 只用渲染与页数 |

## 4. 风险与遗留

- 界面视觉（全屏布局、悬浮按钮位置、面板浮层动画）尚未人工确认。
- Windows 首屏已启动验证（`driftDatabase` 落盘打开无异常）；Android 端 SQLite 首次打开耗时待真机验证。
- 页码指示、缩放（M2）、目录（M3）、划线（M5）未接入。
- iOS 未构建验证（无 macOS 环境）。
