## 1. 目标

1. debug 包装到真机（vivo V2278A，`10CDAB0F5C001TJ`）并确认书架可用。
2. 样张推送到 `/sdcard/Download/`，覆盖导入链路。
3. 查清「导入 PDF 时闪退一次」的根因；用户决定：暂不可复现即结案。

## 2. 证据

| 项 | 结果 |
| --- | --- |
| 系统 crash 缓冲区 | 无该包记录 |
| dropbox | 无该包记录 |
| tombstone | 无法直接读取（非 root），系统侧未见相关条目 |
| 应用日志 | 用户侧只有三条 `[BOOT]`；本轮已补齐 `[IMPORT]` 全阶段日志 |
| 窗口/进程事件 | 同一 PID 13670 三次启动、全程存活，无 `am_proc_died` / ANR |
| 结束方式 | `wm_finish_activity reason=app-request`（15:03:08.980、15:04:01.266、15:04:11.697）→ `wm_destroy_activity` → `wm_task_removed` |
| 内存 | `am_pss` 约 386 MB（swap 492 MB），vivo fast_freezer 频繁冻结/解冻 |

结论：不是进程级崩溃，而是导入过程中 Activity 被结束；选择结果落入插件 LostDataStore 后未取回，表现为「闪退且没有提示」。

## 3. 复现尝试

| 样本 | 结果 |
| --- | --- |
| `sample_large.pdf`（1.50 MB / 1200 页） | 成功，约 1.5 s |
| `sample_broken.pdf`（2.06 KB，伪造 `%PDF-` 头） | 失败提示「文件已损坏，无法解析」，进程不退出 |
| 重复导入 | 哈希去重，提示「1 本已在书架」 |
| 用户 PDF（t1_096484 / t2_links / t3_fluid） | 全部成功 |

全部无法复现，按「暂不可复现」结案。

## 4. 保留的改动

| 文件 | 变更 |
| --- | --- |
| `lib/core/utils/app_logger.dart` | 新增 `beginSession()` / `endSession()`：启动写 `session.marker`，正常退出删除；启动时残留则记 `[WARN] [BOOT] 上次未正常退出` |
| `lib/main.dart` | 启动流程加入 `AppLogger.beginSession()` |
| `lib/app/app.dart` | `AppLifecycleListener` 在 detach / exit 时写结束标记 |
| `lib/features/library/application/library_controller.dart` | 导入拆为 `pickAndImport()` + `_importFiles()`；新增 `recoverLostImport()` 取回 LostDataStore；异常收口为失败提示 |
| `lib/features/library/presentation/library_page.dart` | `initState` 触发一次 `recoverLostImport()`，恢复被系统打断的导入 |
| `lib/data/repos/document_repository.dart` | `importFile` 增加哈希、打开、页数、文字层、复制、封面阶段日志 |
| `pubspec.yaml` | 新增直接依赖 `android_file_picker: 2.1.6`（取回 LostDataStore 所需） |

这些改动都走正常路径之外的兜底，不改变既有导入行为。
