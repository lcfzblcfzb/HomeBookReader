## 2. 项目目标与范围

### 2.1 一句话定位

一个**本地优先、无账号**的跨端 PDF 阅读器，专注「读得进去 + 记得下来」：流畅阅读、按章节快速跳转、书签、文本划线并附个人心得。

### 2.2 本期范围（必须交付）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | PDF 阅读 | 打开本地 PDF、单页翻页（含点击左右区域翻页）、缩放、页码显示、阅读进度记忆（交互形态见 §2.4） |
| F2 | 书架/文档库 | 导入、列表展示、封面、最近阅读、删除 |
| F3 | 目录与章节快速预览 | 解析 PDF outline，树形目录，跳转，章节预览（目标页缩略图） |
| F4 | 书签 | 按页/页内位置添加、列表、跳转、删除 |
| F5 | 文本划线 + 心得 | 文本选择高亮、逐页存储、附心得、标注列表、点击定位 |
| F6 | 三端可用 | Android / iOS 为主目标，Windows 桌面兼顾可用 |

隐含的非功能要求：

- 全离线：除崩溃上报（默认关闭）外不发起任何网络请求。
- 数据本地化：文档副本 + SQLite 均存于应用私有目录。
- 位置可移植：所有阅读位置、书签、划线统一使用「文档 id + 页码 + 页内归一化坐标」，与设备、屏幕尺寸、缩放级别无关。

### 2.3 明确不做（本期 Non-goals）

以下内容**本期不实现、不排期**，评审时不得作为缺陷提出：

1. 账号体系、登录、云同步、多设备自动迁移。
2. OCR / 扫描件文字识别（扫描件只做提示降级，见 R1）。
3. PDF 编辑能力：合并、拆分、页面增删、表单填写、数字签名、注释导出回 PDF。
4. 手写批注、自由绘图、矩形/区域框选标注（仅文本划线）。
5. 全文搜索（文本层已具备，可作为下一期 F7，见 §10）。
6. 翻页动画、仿真翻页、双页对开、自动朗读 TTS、翻译、词典取词。
7. 多窗口（Windows）、标签页多文档同屏。
8. 云盘/局域网/Wi-Fi 传书导入，仅支持系统文件选择器选本地文件。
9. 加密 PDF 的口令输入与解密（导入时识别并提示不支持，见 D5）。
10. 标注分享为图片或导出文件、标注云端备份。

### 2.4 界面形态与交互基线（优先于 §6 中相关描述）

> 本节为产品负责人在开工时确认的界面要求。与 §6 里程碑任务描述冲突时，以本节为准。

整体原则：**极简，无常驻工具栏**。全局只有三种模式，模式之间靠显式交互切换。

| 模式 | 进入方式 | 界面构成 | 退出方式 |
| --- | --- | --- | --- |
| 阅读模式 | 从书架打开文档；书签模式点空白/返回 | 全屏只展示当前页（单页翻页，不连续滚动）；页面层之上仅保留一个悬浮书签按钮 | 返回键/返回手势回书架 |
| 书签模式 | 点击阅读页的悬浮书签按钮 | 书签面板浮到阅读层之上，可查看与管理书签（本轮只做入口 + 基础列表） | 返回键/点击面板外区域 |
| 书架模式 | App 启动默认页；阅读页返回 | 已导入 PDF 列表、导入新文件、应用设置入口 | 打开某本书即进入阅读模式 |

翻页规则（阅读模式）：

1. 点击屏幕**左侧区域**为上一页，**右侧区域**为下一页；中间预留区域（用于后续选中/呼出交互）本轮不绑定翻页。
2. 第 1 页点击左侧、末页点击右侧无效果（不循环、不提示弹窗）。
3. 翻页为单页瞬时切换，不做水平滑动/仿真翻页动画（与 §2.3 第 6 条一致）。
4. 页码指示不常驻，仅在翻页后短暂显示（本轮可先不做，M2 再补）。

由此产生的范围调整：

- §6 M2 中的「连续垂直滚动」「常驻工具栏（返回/目录/书签/标注/页码/跳页）」「沉浸模式点击切换」不再适用；M2 改为「单页翻页 + 点击分区 + 悬浮书签入口 + 缩放」。
- 目录（F3）与标注（F5）的入口后续在书签模式的面板内以页签形式扩展，不再占用常驻工具栏。
- 阅读进度仍按 `page_index + offset_y` 存储，单页模式下 `offset_y` 恒为 0（保留字段以兼容后续缩放/滚动）。

## 5. 数据模型

### 5.1 坐标规范（核心约定，全项目唯一标准）

1. **基准**：以「用户实际看到的页面显示框」（旋转后的 crop box）为基准，左上角为原点，x 向右、y 向下，取值归一化到 `[0, 1]`。
2. **不存像素**：任何情况下不持久化像素值、屏幕坐标或缩放后的尺寸；像素仅在渲染时由归一化值反算。
3. **页码**：统一 `pageIndex`，**0 基**；仅 UI 展示时 `+1`。DB、代码、日志全部 0 基。
4. **矩形集合**：一次划线可能跨多行，存为 `rects = [[x0,y0,x1,y1], ...]`，按「先行后列」的阅读顺序排列；跨页选择按页拆成多条记录，各自携带自己的 `pageIndex`。
5. **精度**：`double`，入库前四舍五入保留 6 位小数，并 `clamp(0,1)`；反算为像素时允许 ±1px 误差。
6. **渲染一致性**：同一标注在 100% / 200% / 400% 缩放下，反算回 PDF 用户空间的几何误差 < 1e-3，不得出现随缩放漂移。
7. **旋转**：本期不支持用户手动旋转页面，归一化相对页面固有朝向；若后续引入手动旋转，必须在标注上补记 `rotation` 快照并按 90° 变换（预留字段，本期不实现）。
8. **窗口/屏幕变化**：旋转屏幕、Windows 改窗口大小后，标注与文本的相对位置不得变化。

### 5.2 表结构

> 以下为逻辑模型，具体类型以 ORM 实现为准；所有时间字段为 epoch 毫秒（INTEGER）。

**documents** — 文档库

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | TEXT | PK | UUID v4 |
| sha256 | TEXT | NOT NULL UNIQUE | 文件内容哈希，用于去重与「换设备/换文件」校验 |
| title | TEXT | NOT NULL | PDF 元数据标题，缺失时用文件名 |
| author | TEXT | NULL | 作者 |
| rel_path | TEXT | NOT NULL | 相对应用私有目录的路径（**禁止存绝对路径**，R7） |
| cover_rel_path | TEXT | NULL | 首页缩略图相对路径 |
| page_count | INTEGER | NOT NULL | 页数，打开时缓存 |
| file_size | INTEGER | NOT NULL | 字节数 |
| has_text_layer | INTEGER | NOT NULL | 0/1，是否具备可用文字层（R1 降级依据） |
| added_at | INTEGER | NOT NULL | 导入时间 |
| last_opened_at | INTEGER | NULL | 最近打开时间，书架排序用 |

**reading_progress** — 阅读进度（每文档一条）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| document_id | TEXT | PK, FK → documents(id) ON DELETE CASCADE | |
| page_index | INTEGER | NOT NULL | 0 基当前页 |
| offset_y | REAL | NOT NULL DEFAULT 0 | 页内位置，0–1 |
| zoom | REAL | NULL | 上次缩放倍数（可选恢复） |
| updated_at | INTEGER | NOT NULL | |

**bookmarks**

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | TEXT | PK | UUID |
| document_id | TEXT | NOT NULL, FK CASCADE | |
| page_index | INTEGER | NOT NULL | |
| pos_y | REAL | NOT NULL | 页内归一化 y，0–1 |
| label | TEXT | NOT NULL | 默认「第 N 页」 |
| excerpt | TEXT | NULL | 该位置附近文本片段（有文字层时） |
| created_at | INTEGER | NOT NULL | |

**highlights** — 划线 + 心得

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | TEXT | PK | UUID |
| document_id | TEXT | NOT NULL, FK CASCADE | |
| page_index | INTEGER | NOT NULL | |
| rects_json | TEXT | NOT NULL | `[[x0,y0,x1,y1], ...]` 归一化 |
| text_snapshot | TEXT | NULL | 选中文字快照；提取异常时可空（R4） |
| note | TEXT | NULL | 心得正文，NULL/空表示仅高亮 |
| color | INTEGER | NOT NULL | ARGB |
| created_at | INTEGER | NOT NULL | |
| updated_at | INTEGER | NOT NULL | |

> 取舍：`rects` 用 JSON 存储而非独立子表。理由：划线永远按页整块读写，无需按矩形查询；子表会增加 join 与事务成本。若后续需要按矩形检索（如去重合并），再迁移。

**toc_entries** — 目录缓存（避免每次打开重复解析）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | TEXT | PK | UUID |
| document_id | TEXT | NOT NULL, FK CASCADE | |
| parent_id | TEXT | NULL | 自引用，根为 NULL |
| title | TEXT | NOT NULL | 章节标题 |
| level | INTEGER | NOT NULL | 层级，从 1 开始 |
| page_index | INTEGER | NOT NULL | 目标页，0 基 |
| sort_order | INTEGER | NOT NULL | 同级排序 |

**app_meta** — 键值元信息

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| key | TEXT | PK | 如 `last_library_sort` |
| value | TEXT | NOT NULL | |

### 5.3 索引与约束

- `documents(sha256)` UNIQUE；`documents(last_opened_at DESC)`。
- `reading_progress(document_id)` PK。
- `bookmarks(document_id, page_index)`；`highlights(document_id, page_index)`。
- `toc_entries(document_id, sort_order)`；`toc_entries(document_id, parent_id)`。
- 所有子表外键开启 `ON DELETE CASCADE`，配合 SQLite `PRAGMA foreign_keys = ON`，保证删文档时数据级联清零（验收 S4）。

### 5.4 文件与迁移

- 私有目录：`pdfs/{documentId}.pdf`、`covers/{documentId}.webp`，DB 存相对路径，启动时用应用目录重新拼绝对路径。
- 删除文档：先删 DB（级联）再删文件；文件删除失败只记日志，不阻断，下次启动做孤儿文件清理。
- 迁移：启用 ORM schema 版本号，每次建表变更必须附「旧版本数据升级到新版本」的迁移测试；破坏性变更新增导出/导入方案前不得直接删除列。

## 6. 里程碑与任务清单

   - S3 目录：能否读取 outline（标题/层级/目标页），无 outline 时的行为。
   - S4 落库：SQLite 在三端读写与大批量查询的基线。
7. 记录 ADR：ORM、状态管理、路由、pdfrx 锁定版本（含 API 片段）。

**完成条件（DoD）**

- [ ] 三端均可运行，能打开内置样本 PDF 并连续滚动。
- [ ] S1–S4 均有书面结论，明确「可行 / 有坑 / 不可行 + 应对」。

- [ ] 决策清单 D1/D2/D3 定稿并写入文档。

### M1 书架与导入

**目标**：把文件变成「我的书」，并保证数据落地可靠。

任务：

1. 导入流程：系统文件选择器（Android SAF、iOS UIDocumentPicker、Windows 文件对话框），支持多选；另有「扫描本机 PDF」遍历本机存储批量导入（Android 11+ 需「所有文件访问权限」，详见 [M2-2](./TODO/M2-2-扫描本机PDF.md)）。
2. 校验：扩展名 + PDF 头校验；损坏文件、加密文件给出明确提示并拒绝入库（D5 决策后执行）。
3. 入库：复制到私有目录 → 计算 sha256 → 解析元数据（标题/作者/页数/`has_text_layer`）→ 生成封面 → 写 `documents`。
4. 去重：同 sha256 已存在时提示「已在书架」并跳转，不产生重复记录。
5. 书架 UI：网格/列表切换、最近阅读排序、标题搜索、空态引导、导入进度与失败重试。
6. 删除：二次确认，级联清理进度/书签/划线/目录/缓存文件。
7. 数据层：`documents`、`reading_progress` 表 + DAO + `DocumentRepository`。
8. 文件缺失处理：启动/打开时校验文件存在，缺失则标记并提示重新导入（本期不实现「重新关联」UI）。
9. EPUB 支持（第一步，M1-015）：仅 EPUB2 / EPUB3；导入校验 ZIP 容器 + `mimetype` + OPF，解析书名/作者/封面与 nav/ncx 目录落库；书架与 PDF 混排，进度用「位置」百分比；扫描同时识别 EPUB。
10. EPUB 阅读页（第二步，M1-016）：分页排版（不做滚动），左右点击翻页、跨章连续、末尾提示；目录 `href + fragment` 跳转；位置书签；字号 5 档 / 行距 2 档放在书签面板「排版」页签；进度存 `position`，跨字号、屏幕尺寸、横竖屏恢复；按章懒排版 + 渐进排版。

**完成条件（DoD）**

- [ ] 三端各导入 3 类样本 PDF 成功；杀进程重启后书架完整保留。
- [ ] 重复导入同一文件不新增记录，并跳转到已有条目。
- [ ] 删除文档后，四张子表关联行数为 0、私有目录无残留文件（可断言）。
- [ ] 损坏/加密文件导入时给出明确中文提示，App 不崩溃。
- [ ] 100 本书架首屏渲染 ≤ 1s（封面懒加载）。
- [ ] Windows 冒烟通过（拖拽导入不在本期范围，仅文件对话框）。
- [ ] 导入 EPUB 后书架显示封面、书名、作者；点开进入分页阅读页且不崩溃，退出重进回到原处（M1-016）。

### M2 阅读器核心

> 交互形态以 §2.4 为准：单页翻页 + 点击左右区域翻页 + 悬浮书签按钮，无常驻工具栏。以下任务中涉及「连续滚动 / 常驻工具栏 / 沉浸模式」的条目按 §2.4 改写后执行。

### M5 划线 + 心得（技术难度最高）

**目标**：把「读到重点」变成可回看的个人笔记。

## 附录 B 术语

| 术语 | 含义 |
| --- | --- |
| 归一化坐标 | 以页面显示框为基准、取值 0–1 的坐标，与像素/缩放无关 |
