# HomeBookReader

本地优先、无账号的跨端 PDF / EPUB 阅读器。

## 初心

市面上的阅读器越做越重：注册账号、云同步、广告、付费会员，一本书打开前先要过三道关。
这个项目的出发点很简单——**书是自己的，阅读就该是自己的事**。

- **本地优先**：文档副本与阅读数据全部存在应用私有目录，除崩溃上报（默认关闭）外不发起任何网络请求。
- **无账号**：不登录、不注册、不联网，装上就能读。
- **读得进去**：极简界面，没有常驻工具栏，全屏只有当前页和一个悬浮入口。
- **记得下来**：阅读进度、书签、大纲位置随文档保存，换设备也不丢——位置统一用「页码 + 页内归一化坐标」描述，与屏幕尺寸、缩放级别无关。

它不试图成为一个全能 PDF 工具箱，只想把「打开一本书 → 读进去 → 回头能找到」这条主线做顺。

## 功能

| 功能 | 说明 |
| --- | --- |
| PDF 阅读 | 打开本地 PDF，单页翻页（点击左右区域翻页）、缩放、阅读进度记忆 |
| EPUB 阅读 | 自建 ZIP / OPF / NCX / nav 解析，章节分页阅读 |
| 书架 | 导入、列表、封面、最近阅读、删除 |
| 扫描本机 PDF | 自动遍历本机存储，按文件头 `%PDF-` 识别，带进度提示与损坏 / 加密文件标记，Android 与 Windows 双端支持 |
| 目录大纲 | 解析 PDF outline 与 EPUB 章节树，树形展示、跳转、章节预览 |
| 书签 | 悬浮入口可拖拽吸附、三态状态机；按页 / 页内位置添加、列表、跳转、删除 |
| 三模式界面 | 书架 ⇄ 阅读 ⇄ 书签面板，靠显式交互切换，无常驻工具栏 |
| 运行日志 | 全阶段日志与轮转，便于排查无痕迹问题 |

**明确不做**（本期范围外）：账号与云同步、OCR、PDF 编辑、手写批注、全文搜索、翻页动画、加密 PDF 解密。

## 平台

Android / iOS 为主目标，Windows 桌面兼顾可用。

## 技术栈

- **框架**：Flutter 单代码库
- **PDF 渲染**：`pdfrx`（PDFium 封装），版本锁定、只允许出现在 `core/pdf`
- **状态管理**：`flutter_riverpod`
- **路由**：`go_router`
- **本地存储**：SQLite（`drift`）
- **EPUB 解析**：`archive` + `xml` 自建

## 运行

```bash
# Windows 桌面
./run_windows.ps1

# Android
./run_android.ps1
```

或直接：

```bash
flutter pub get
flutter run -d windows
```

## 测试

```bash
flutter test
```

## 目录结构

```
lib/
├── app/        # 应用壳与主题
├── core/       # pdf / ebook / storage / geometry / platform（平台与渲染抽象）
├── data/       # drift 数据库与仓库
└── features/   # library / reader / bookmarks / toc / scan / settings
DOC/            # 开发大纲、里程碑 TODO、模块说明与验收记录
```

依赖方向自上而下，禁止跨层反向依赖；`pdfrx` 只在 `core/pdf` 出现，其余层只依赖 `PdfEngine` 抽象。
